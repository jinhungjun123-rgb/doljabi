# 돌잡이 — "일반 지원 더 보기" 설계

**날짜:** 2026-11-01 · **상위 설계:** `2026-11-01-doljabi-mobile-web-design.md` 8절 ("나중에 할 것") · **상태:** 팀과 합의 (채팅에서)

## 목적
결과 화면의 "+ 함께 받을 수 있는 일반 지원 더 보기" 자리를 채운다. 가족돌봄 전용 14개(팀 검수) 말고, 이 사용자가
함께 받을 수 있는 일반 청년·복지 지원을 **조건별 자동 판정**과 함께 보여 주고, 원문과 채팅으로 이어 준다.

## 범위
- 출처 두 가지 (자동 판정할 수 있는 것만, 팀 결정):
  - **온통청년 청년정책** (`raw/2026-11-01/youth.json`, 3,843개): 신청 기간이 끝나지 않았고 소득 조건이 "무관" 또는 "연소득 범위"인 것.
  - **복지로 국가 서비스** (`raw/2026-11-01/national.json`, 461개): 생애주기에 청소년 또는 청년이 있는 것. 대상이 보훈대상자·다문화·탈북민뿐인 것은 뺀다.
- 뺀다: 복지로 지자체 서비스(`local.json`, 나이·소득 정보가 없어 판정 불가), 팀 검수 14개와 같은 사업(복지로 ID, 온통청년 정책번호로 비교).
- 실행 중에는 공공 API를 부르지 않는다. 데이터 기준일 2026-11-01을 화면에 적는다.
- 사용자 한 명에게 대략 300~400개가 나온다 (충북 20세 약 390, 서울 28세 약 370).

## 데이터
`scripts/build_more.py`: raw → `data/programs/more.json` (생성물, 커밋, 손으로 고치지 않음). 항목:
`id, source("youth"|"national"), name, summary(한 줄), org, link, group, region_codes, age, income, period, job, school, life, targets, online`.
링크: 온통청년은 정책 상세 페이지(정책번호), 복지로는 `servDtlLink`.

## 판정 (`src/ragbot/domain/more.py`, LLM 없음)
조건마다 ok / unknown / no, 카드 상태 규칙은 기존과 같다 (no 하나면 어려워 보여요, 모두 ok면 받을 수 있어 보여요, 나머지 확인이 필요해요).
답하지 않은 항목은 항상 unknown.

| 조건 | 청년정책 | 국가 서비스 |
|---|---|---|
| 나이 | 나이 제한 없음 → 행 없음. 범위 안 ok, 밖 no | 청소년 13~18, 청년 19~34 (군 복무 연장은 쓰지 않음): 해당 ok, 아니면 no |
| 지역 | 내 시·도가 대상에 없으면 **목록에서 뺌**. 전국·시·도 전체 ok. 일부 시·군·구만이면: 입력한 시·군·구가 담당 기관 이름에 있으면 ok, 없으면 unknown | 없음 (전국) |
| 소득 | 무관 → 행 없음. 연소득 범위: 앱의 월 소득 구간 ×12 가 범위 안 ok, 전부 밖 no, 걸치면 unknown | 대상에 저소득: 수급·차상위 ok, 아니면 unknown |
| 신청 기간 | 상시 ok. 기간 지정: 진행 중 ok, 시작 전 unknown, 끝남 → **목록에서 뺌**. 미정 unknown | 없음 |
| 취업·학업 상태 | 코드가 "제한 없음"이면 행 없음. 아니면 앱의 "지금 무엇을 하고 있나요"와 대응되는 코드면 ok, 아니면 no. 코드 뜻은 원본 표본으로 확인한 것만 쓰고, 확인 못 한 코드는 unknown | 대상에 장애인·한부모 등: unknown |

"오늘"은 요청 시점(한국 시간)이다. 모든 항목 아래에 "그 밖의 세부 요건은 원문에서 확인"을 적는다 (조건 행이 아님).

## 분야와 순서
분야 6개: 생활·금융 / 건강·마음 / 교육 / 일자리 / 주거 / 참여·문화. 청년정책 대·중분류와 국가 서비스 관심 주제를 이 6개에 대응시킨다.
분야 안 순서: 받을 수 있어 보여요 → 확인이 필요해요, 같은 상태에서는 이름·설명에 돌봄·가족·간병·장애가 있는 것 먼저, 그다음 내 지역 사업, 그다음 이름순.
화면에는 분야마다 4개를 먼저 보이고 "더 보기"로 펼친다. 어려워 보여요는 분야마다 "조건이 맞지 않아 보이는 N개" 로 접는다.

## API
`POST /api/more {"profile"}` → `{"as_of", "groups": [{"key", "label", "items": [...], "no_items": [...]}]}`. 항목에는 조건별 결과가 붙는다.
깨진 프로필은 `clean_profile` 로 정리. 서버는 아무것도 저장하지 않는다.
`POST /api/chat` 은 선택 `about: {name, org, summary, link}` 를 받는다: 글자 수 제한, http(s) 링크만, 시스템 프롬프트 맥락에
"공공데이터의 사업, 법령 문서에 없음, 공식 사이트 웹 검색으로 확인" 문장으로 붙는다 (문장은 도메인 코드에서 만든다).

## 화면
- 결과 화면의 "더 보기" 칸 → 새 화면 "일반 지원" (탭은 내 지원). 맨 위: "공공데이터를 자동으로 정리하고 판정한 목록이에요 (2026-11-01 기준). 받을 수 있는지는 원문과 담당 기관에서 확인하세요."
- 항목 카드: "자동 확인" 배지(검수 14개의 "법령 확인"과 구분), 상태, 이름, 한 줄 설명, 출처(청년정책 / 국가 서비스).
- 상세: 조건별 ✅❓❌, 설명, 담당 기관, 신청 기간, "원문 보기 ↗", "물어보기" → 채팅(그 사업 정보를 함께 보냄).

## 테스트

"전남광주통합특별시")의 지역 코드, 검수 14개 제외, 정렬. `tests/test_api.py`: `/api/more`, `about` 정리(긴 글, javascript 링크).
390px 화면 확인: 결과 → 더 보기 → 상세 → 물어보기.
