# 0011 — 잘못 읽기 쉬운 조문에 읽는 법(note)을 붙이고, 하위 목록을 색인에 넣는다

**상태:** 채택 · 2026-11-03

## 배경
최종 점검(실제 사이트)에서 내 정보 없이 "군대를 2년 다녀와서 지금 35살인데 자기돌봄비를 신청할 수 있나요?"(K05)에
"신청할 수 없습니다"라고 답했다. 검색은 맞았다(시행령 제11조①1). 모델이 "병역의무를 이행한 기간을 가산한다"를
사용자 나이에 더하는 것으로 읽었다. K05 는 그때까지 실행 9번 모두 틀렸다. 시스템 프롬프트 규칙은 0007 에서 다른 문항을 떨어뜨려 되돌렸다.

조사하다가 색인 버그도 찾았다: kordoc 목록 블록의 하위 항목(`children`)을 `ingest/sections.py` 가 버려서
법 제13조①1 가~라목(가족돌봄 선정 요건), 법 제2조1호 가~다목 등이 검색되지 않았다 (색인에서 빠진 줄: 법 56, 시행령 약 70, 시행규칙 12).

## 결정
- `config.yaml → documents.notes`: `{match: 정규식, note: 읽는 법}` 목록. `search_documents` 결과 중 문단이 정규식과 맞으면
  `note` 를 본문 앞에 붙인다 (코어 `tools/core.py` 는 일반 기능만, 법령 문구는 설정에). 질문이 아니라 **문단**에 붙으므로
  그 조문이 검색되는 모든 질문에 똑같이 작동한다. 지금 셋:
  1. 병역 가산 (시행령 제11조①1, 법 제2조1호): 상한 = 34세 + 복무 기간, 지금 나이와 비교. 예시는 1년 복무 (점검 질문과 다른 숫자).
  2. 주소 일치와 예외 (법 제13조①1다목, 시행규칙 제6조②): 학업·취업으로 옮겼어도 정기 방문·실제 돌봄이면 충족.
  3. 선정 요건 조문(법 제13조)에는 나이가 없음 → 법 제2조1호(34세 이하), 13세 미만은 드림스타트 (보도자료).
- `ingest/sections.py`: 목록의 `children` 을 들여쓰기(`  - `)로 이어 붙인다. `python -m ragbot index` 로 색인을 다시 만들었다 (113 섹션 → 121 청크).
- note 는 본문 앞에 둔다 (뒤에 두면 K01 이 3번 모두 나이를 빠뜨림, 앞에 두면 1번).
