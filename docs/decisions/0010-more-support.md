# 0010 — 일반 지원 더 보기: 공공데이터 자동 판정

**상태:** 채택 · 2026-11-01 · 설계: `docs/superpowers/specs/2026-11-01-doljabi-more-support-design.md`

## 배경
결과 화면의 "일반 지원 더 보기"는 자리만 있었다. 팀이 검수한 가족돌봄 지원 14개 말고도 함께 받을 수 있는 청년·복지 지원을,
받을 수 있는지와 함께 보여 주기로 했다 (팀 결정). 검수 없이 하루 안에 해야 한다.

## 결정
- 출처: 온통청년 청년정책 + 복지로 국가 서비스(청소년·청년). 복지로 지자체 서비스는 나이·소득 칸이 없어 뺐다 (팀 결정).
  `scripts/build_more.py` 가 raw → `data/programs/more.json` (youth 2,097 + national 168). 실행 중 공공 API 호출 없음.
- 판정은 `domain/more.py` (LLM 없음): 나이, 지역, 소득, 신청 기간, 취업·학업 상태(뜻을 확인한 코드만), 대상.
  다른 시·도 사업과 신청이 끝난 사업은 목록에서 뺀다. 카드 상태 규칙은 `eligibility.py` 와 같다. 배지는 "자동 확인".
- **데이터로 판정할 수 없는 제한은 "확인 필요" 행으로**: 특화 대상 코드, 혼인 코드, 글로만 적힌 추가 자격, "나이 제한 있음 0~0세"(630개),
  복지로 국가 서비스 전부(자격이 설명 글에만), 이름에 특정 대상이 드러나는 사업(자립준비, 장애, 한부모, 농업인 …).
  처음 구현에서는 가정양육수당·0세반·자립수당이 20세 대학생에게 "받을 수 있어 보여요"로 나왔다.
- 채팅: 상세의 "물어보기"는 사업 이름·기관·설명·원문 링크를 `about` 으로 보낸다. 서버는 글자 수를 자르고 http(s) 링크만 남겨
  시스템 프롬프트 맥락에 붙인다. 문서에 없는 사업이라 채팅은 웹 검색으로 답한다.

## 대안
- 공공 API를 그때그때 호출: 느리고 키가 서버에 있어야 해 기각.
- 판정 없이 목록만: 팀이 "받을 수 있는지 알 수 있게"를 원해 기각.
- 복지로 지자체 서비스를 "확인 필요"로만 포함: 팀이 자동 판정 가능한 것만 쓰기로 해 기각.

## 추가 (리뷰 반영, 2026-11-02)
- 담당 기관이 시·도/시·군·구면 zipCd 에 전국이 적혀 있어도 그 지역 사업으로 본다. 사용자에 대해 맞는 조건(나이·지역·소득·취업·학업·대상)이
  하나도 없으면 "받을 수 있어 보여요"가 아니라 "확인이 필요해요". 소득은 개인·가구 기준을 알 수 없어 범위 밖도 "확인 필요".
  시·군·구는 낱말 단위로 비교 ("용인시 수지구" → 용인시, "양주" ≠ 남양주). `/api/more` 는 gzip (약 470KB → 약 70KB).
- 데이터 정리: HTML 기호를 글자로, 이름·기관이 같은 중복 제거, 신청할 수 없는 행정 업무(위원회 운영, 실태조사, 조성·개발사업 등) 제외,
  주거와 관계없는 "주거" 분류는 생활·금융으로, "나이 0세 이상"은 나이 제한 없음으로. youth 2,097 → 1,935, national 168 → 166.
- 채팅 `about` 은 사업 번호만 보내고 서버가 정리 파일에서 찾는다 (화면이 보낸 글이 시스템 프롬프트에 들어가지 않음).
- 분야 순서는 설계대로: 생활·금융 / 건강·마음 / 교육 / 일자리 / 주거 / 참여·문화.
- 충북 청주 20세 대학생: 받을 수 있어 보여요 14, 확인이 필요해요 544, 어려워 보여요 48. 테스트 87 passed, 2 skipped.

## 추가 (짧은 목록, 2026-11-02, 팀 결정)
"확인이 필요해요"가 500개가 넘어 너무 많았다. 화면은 약 30개만 보여 준다.
- 받을 수 있어 보여요는 모두. 그 아래 "확인해 볼 만한 지원"은 분야마다 3개 (최대 18개): 특정 대상·혼인 조건은 빼고,
  돌봄·간병 관련 → 내 지역 → 모르는 조건이 적은 것 → 지금 신청 가능 순. 어려워 보여요는 보내지 않는다. 나머지는 온통청년·복지로 링크.
- 받을 수 있어 보여요가 0개면 "정보를 더 입력하면 골라 드려요 → 내 정보 수정" 안내.
- 같은 이름(해마다 다시 올라온 "2026 …")은 한 번만. 이름에 다른 시·도가 있으면 그 지역 사업. 특정 대상 낱말 추가(양육·출산·결혼·농지·특수학교·피해자·의사상자·입양·위탁·자활 등).
  돌봄 순위 낱말은 돌봄·간병·영케어러만 ("가족"은 너무 넓음). 신청할 수 없는 시스템 구축·DB 고도화 제외.
- `/api/more` 응답 `{"as_of", "ok": [...], "maybe": [{"key", "label", "items"}]}`, 약 17KB. 충북 청주 20세 대학생: 11 + 18. 테스트 94 passed, 2 skipped.
