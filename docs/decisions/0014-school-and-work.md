# 0014 — 4단계를 "학교"와 "일" 두 질문으로, 청년성장프로젝트의 "미취업" 조건 삭제

날짜: 2026-11-03 · 팀 결정

## 문제
4단계 "지금 무엇을 하고 있나요?"는 하나만 고르게 해서(중·고등학생 / 대학생 / 일하고 있어요 / 쉬고 있어요 6개월 넘게·안),
대학에 다니면서 아르바이트하는 청년을 담지 못했다. 또 청년성장프로젝트 상세의 조건 "미취업"이 "미취업이면 안 된다"로 읽혔다.

## 결정
- 프로필 `activity` 하나 → `school` (middle_high / college / none) + `work` (working / none) + `rest` (6m_plus / under_6m,
  학교도 일도 안 할 때만 묻는다). 아무거나 여러 개 고르는 방식은 "일함 + 6개월 넘게 쉼" 같은 말이 안 되는 조합이 생겨서 쓰지 않았다.
- 예전에 저장된 `activity` 는 화면(`web/app.js fromActivity`)과 판정(`eligibility.clean_profile`) 둘 다에서 옮긴다. 모르는 칸은 비워 둔다
  (예전 "일하고 있어요"는 학교에 다니는지 몰랐으므로 `school` 없음).
- 판정:
  - 국가장학금: `school == college` 면 보여 준다 (일해도 됨).
  - 청년도전지원사업 "6개월 넘게 취업·교육 이력 없음": 학생이거나 일하면 미충족, 학교·일 둘 다 안 하고 6개월 넘었으면 충족.
  - 청년성장프로젝트: "미취업" 조건을 뺐다. 고용24 안내 "15세 ~ 34세 청년 누구나", 복지로 안내(2024-04-22) "입사 초기 청년을 위한
    프로그램도 있어요". 대신 "학교에 다니지 않음 (졸업예정자·사이버·방송통신·야간대 재학생은 참여 가능)": 고용노동부 포항지청 안내
    (경북매일 2026-08-03) "원칙적으로 교육기관 재학생은 참여할 수 없습니다. 다만 졸업예정자와 사이버대학교·방송통신대학교·야간대학교
    재학생 등 …". 학교에 다니면 확인 필요, 안 다니면 충족. 검수 결정11 (`scripts/build_review.py`).
  - 일반 지원: 일하면 재직자 코드, 학교·일 둘 다 안 하면 미취업자 코드, 학생이 일하지 않으면 모름 (정책마다 재학생을 넣거나 뺀다).
