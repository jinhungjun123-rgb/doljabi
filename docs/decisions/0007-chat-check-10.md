# 0007 — 채팅 점검 질문 10개 (템플릿의 골든 QA 20~30개 대신)

**상태:** 진행 중 · 2026-11-01 · 질문과 정답은 팀이 확인 (K05 는 확인 대기라 빠짐)

## 배경
앱의 핵심은 규칙 코드 판정(`domain/eligibility.py`, 테스트로 검사)이고, 채팅은 이어 묻기다. 하루 안에 끝내야 해서
템플릿의 골든 QA 20~30개와 시나리오 점검 대신, 실제로 자주 틀리는 곳(1회/연, 단서·예외, 신청처)을 고른 10개로
채팅을 바꾸기 전후의 정답 수를 비교한다. `eval/thresholds.yaml` 은 그대로 둔다 (낮추지 않음).

## 결정
- `eval/golden_qa.jsonl`: K01–K04, K06–K10 (9개). K05(병역 기간만큼 나이 상한 연장)는 팀 확인 후 넣는다.
- 채팅을 바꾸는 수정은 이 9개(이후 10개)의 정답 수가 줄면 되돌린다.

## 결과
| | 정답 | 비고 |
|---|---|---|
| 기준 (`runs/eval_20261101_222214.json`) | 7/9 | K06, K07 틀림. 라우팅 9/9 |
| 시스템 프롬프트에 "조건과 예외가 다른 조문에 있다" 규칙 추가 (`runs/eval_20261101_222414.json`) | 6/9 | **되돌림** |

틀린 원인 (trace):
- K06: 검색은 맞다 (시행규칙 제6조②가 2위). 답이 제3조(서류)만 근거로 써서 예외를 말하지 않음 → 답 생성.
- K07: 질문의 "형"을 돌봄대상가족으로 읽음. "35세 이상 다른 가족" 요건으로 읽지 않음 → 질문 문장이 두 가지로 읽힘.
- 규칙 추가 후 K06 은 예외 내용을 말했지만 채점 단어("예외", "인정")가 없었고, K08 은 내용은 맞지만
  "아동·청년(즉, 당신)의 소득"이라 채점 단어와 어긋남. 채점 키는 고치지 않는다 (AGENTS.md 경계).

## 대안
- 채점 단어를 넓히기: 통과시키려고 키를 바꾸는 것이라 기각.
- 질문별 규칙을 프롬프트에 넣기: 숨겨진 질문 평가와 맞지 않아 기각.
